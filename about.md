Hi! I'm **rhtnll2026**. This is my corner of the internet, where I write about
the things I'm building, learning, and thinking about.

## What you'll find here

- **Notes** — short write-ups of things I figured out, so future-me doesn't have to again.
- **Projects** — what I'm working on, and what went wrong along the way.
- **Ideas** — longer posts when something won't leave my head.

## About this site

This blog is a static site built with [Jekyll](https://jekyllrb.com) and hosted
for free on [GitHub Pages](https://pages.github.com). Every post is a plain
Markdown file in the [`_posts/`](https://github.com/rhtnll2026/rhtnll2026/tree/main/_posts)
folder — pushing a new file publishes it automatically.
